# HEARTBEAT - Agenda do Timesheet Monitor

## A cada 30 minutos (7h-21h, dias uteis)

- Verificar clock-ins ativos sem clock-out ha mais de 12h → alerta imediato
- Verificar anomalias de GPS nos registros recentes

## Diario - 20h

- Listar trabalhadores ativos sem registro no dia
- Enviar lembrete via WhatsApp para cada um

## Diario - 21h

- Calcular totais diarios de horas por projeto
- Consolidar custos do dia
- Registrar flags de hora extra

## Semanal - Sexta-feira 18h

- Gerar resumo semanal por projeto para gestores
- Consolidar horas extras da semana
- Flaggar aprovacoes pendentes ha mais de 7 dias
- Enviar relatorio para cada gestor de projeto
